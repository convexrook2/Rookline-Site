Rookline for Windows

Turn a drive into the next useful decision.

Rookline brings session evidence, engineering priorities, and recorded setup controls into one calm place—so the next run starts with a reason.

Download Rookline View the product tour
Windows desktop application · session analysis · setup support · optional AI assistance

01 — Drive evidence

Start with the lap, not the noise.

Choose a recorded session and Rookline keeps its review anchored to the laps, sectors, conditions, and moments that were actually captured.

From review to action

A smaller, clearer engineering conversation.

The product does not ask the driver to interpret a wall of numbers. It makes the next priority inspectable, keeps the supporting evidence close, and leaves control with the driver.

01 / REVIEW

Find the pattern.

Use the completed session to see where time was gained, lost, or repeated before deciding what is worth changing.

02 / PRIORITISE

Carry one reason forward.

Engineer turns the review into a focused next-run brief. It is advice backed by the selected run, not an automatic change.

03 / RECORD

Keep setup work legible.

Setup shows recorded controls and their context so a driver can inspect what changed without losing the run that motivated it.

02 — Engineer priorities

One next run, made inspectable.

Rookline carries the selected session into an engineering brief. The driver can review the context, compare the trace, and decide whether the recommendation belongs in the next run.

Evidence stays nearby

Detail without losing the thread.

When more perspective helps, optional AI assistance can be read alongside the session evidence. It does not replace the driver’s judgment or apply a setup on their behalf.

03 — Setup controls

Recorded controls, clear context.

Setup presents the currently available controls with the saved, live, and recorded context made visible. Changes remain a driver decision, with evidence available for review.

04 — RookForce workspace

Asetek Forte Wheelbase support, inside the same workspace.

Open RookForce from Rookline when you use a supported Asetek Forte Wheelbase. It remains an optional, isolated part of the product, so the rest of Rookline stays useful when wheelbase support is unavailable.
